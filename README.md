# 心之羅盤｜自我領導力英雄之旅

以七個習慣及第八個習慣為骨架的原創情境學習網站。國小、國中、成人各有 80 關，共 240 個生活情境。三條路線進度獨立。

## 學習方式

- 滿版彩色潑墨美國山川場景、八位已故美國人物的 Q 版陪伴角色。
- 每習慣 10 個知識點；故事 → 情境選擇 → 部分關卡配合／排序 → 48 小時生活行動。
- A／B／C／D 對應左／上／下／右或 1／2／3／4；答錯顯示解析，答對進入行動或操作練習。
- 大關與小關清楚標示已過、未過、剩餘數量。
- 答題通關與生活實踐分開，實踐為學習者自行回報，不推論人格或品德。
- 不必輸入姓名；可不分享個人經驗；瀏覽器本機儲存，可匯出／合併匯入 JSON。
- 教師備課室提供 40 分鐘帶班流程、拒絕分享選項、人物史料及概念來源。

## 執行

需要 Node.js 22 以上，網站沒有 npm 執行依賴。

```sh
npm start
# http://127.0.0.1:8796
npm test
npm run build
```

`npm start` 的公開檔案有明確白名單；部署只包含 `dist` 內的網站資產。

## 部署

使用現有 Cloudflare 工具鏈，授權部署後執行 `npx wrangler deploy`。第一次部署前先確認 `npx wrangler whoami`。未部署前不要將預計網址視為已上線。

## 內容與檔案

- `curriculum.json`：8 習慣 × 10 關 × 國小／國中／成人情境、選項、解析、實踐。
- `worlds.js`：人物、各境故事起訖、操作工具與來源。
- `engine.js`：角色分離、去重進度、備份輸入篩選。
- `app.js`、`style.css`：網站互動與響應式滿版呈現。
- `assets`：AI 輔助原創插畫、向量圖示。

歷史人物對話是教學創作，不是本人引言或官方背書。本站不是 FranklinCovey 官方認證課程；未複製其教材。使用者的反思與實踐不作自動道德評分。資料目前僅存在此瀏覽器，尚無 Google 登入與跨裝置雲端同步。
